## 本次自动化验证

`npm run check` 已通过：TypeScript 严格类型检查及 9 项测试（其中 7 项使用临时真实 Git 仓库，2 项验证输出解析）。覆盖无 HEAD、双重修改、中文/换行文件名、重命名、删除、多 worktree、字面 pathspec、路径拒绝、二进制和 Git 错误。

受限沙箱内 `tsx` CLI 的本地 IPC 管道创建被拒绝；同一检查命令在获准的沙箱外执行通过。没有启动或安装到 Paseo。

## 已核对的类型

- `PluginClientContext.addWorkspacePanel`、`addCommandCenterItem`。
- `PluginWorkspacePanelProps` 的 `workspaceId`、`host.id`、`theme`、`layout`。
- `defineRpc`、`useRpc`、`PluginServerContext.handle`，handler 第二参数包含 `paseo`。
- **发行版 SDK 的 `workspaces.ref(id).refresh()` 返回 `workspaceDirectory`**。服务端显式映射成内部 `directory`，不直接套用滚动文档中的字段示例。

- [ ] 记录客户端与 daemon 版本，确认 manifest 允许当前版本。
